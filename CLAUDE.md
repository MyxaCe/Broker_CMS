# Команда cms

Ты отвечаешь за `MyxaCe/Broker_CMS` — **CMS v2**, единственный источник истины по
контенту, структуре сайтов, дизайн-токенам и релизам.

## Не перепутать с legacy

Существуют два репозитория с именем `Broker_CMS` у разных владельцев:

- **`MyxaCe/Broker_CMS` — эта папка.** v2, пишется с нуля по ADR-0006, ни строки
  из текущей CMS. M3 из M6. **Нигде не развёрнута.**
- `MyhaC1/Broker_CMS` — папка `../cms-legacy/`. Та CMS, что реально крутится на
  контуре контейнером `deploy-cms-1`. Заморожена 27.07. Для нас — только
  источник данных для миграции (M6).

Совпадение имён при разных владельцах — готовая ловушка при настройке CI и
деплоя. Проверяй владельца, а не имя.

## Где ты на самом деле

M0, M1, M2 закрыты. **M3 в работе:** слои А и Б собраны, остаётся слой В и
интерфейс редактора — это единственное, что отделяет M3 от приёмки. M4, M5, M6 не
начаты; миграция данных живёт в M6, то есть последней.

Собрано: тенанты с наследованием, изоляция как правило доступа (доказана
автотестом на живой БД), роли, журнал аудита с неизменяемостью на уровне
Postgres, окружение через zod с fail-closed, релизы с откатом, поток целиком,
пять ресурсов выдачи наружу — каждый с ключом, пределом частоты и валидацией
схемой.

## Что НЕ твоё

- **CRM Mica** — другая платформа, не трогаем вообще.
- **Сайт и кабинет** — команда `site-platform`. Ты поставляешь им выдачу, их код
  не правишь.
- **Сервер `91.228.152.4`** — туда ходит только команда `deploy`.
- **Код legacy-CMS** — по ADR-0006 не переносим ни строки. Смотреть на её
  поведение можно, копировать реализацию нельзя.

## Что важно знать до первой правки

**Порядок этапов не произволен.** Изоляция тенантов, аудит и fail-closed
окружение (M0) обязаны существовать *до* появления данных и выдачи.
Ретроспективно навесить изоляцию в регулируемом домене — это миграция с
доказательством, что утечки не было. Перестановка этапов — ADR, а не рабочее
решение по ходу.

**Сайт обязан работать без тебя.** При недоступной CMS сайт отдаёт контент из
фикстур. Правка, ломающая это, неверна независимо от того, насколько удобна.

**Ты — источник производных списков.** Вебхуки на сайты и секреты к ним
заводятся по одному на страну, сегодня руками. Два из шести списков платформы,
которые обязаны совпадать между репозиториями (`../_brain/КОНТРАКТЫ.md`, разд. 6).

**Твоя документация — эталон для остальных команд.** 19 ADR, регламент, журнал,
раздел хвостов и открытых вопросов. Планка задана тобой же — держи её.

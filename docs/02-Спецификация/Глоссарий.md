# 📖 Глоссарий

Чтобы «релиз», «канал» и «витрина» значили одно и то же в коде, документации и разговоре с заказчиком. Пополняется при появлении нового понятия.

## Тенанты и наследование

| Термин | Значение |
|---|---|
| **Тенант (site)** | Отдельный сайт брокерской платформы. Единица изоляции доступа и выдачи. |
| **Цепочка наследования** | `brand (root) → region → site`. Наследуются токены, библиотека блоков и секций, шаблоны страниц, правовой каркас, навигационный скелет, конфиг терминала, комплаенс-правила. |
| **Состояние поля** | `inherited` \| `overridden` \| `forked`. У каждого поля в админке — бейдж источника и кнопка «вернуть к наследуемому». Отвязка от наследования — осознанное действие с записью в аудит. |

## Публикация

| Термин | Значение |
|---|---|
| **Workspace (черновое пространство)** | Пространство правок редакторов. Наружу не отдаётся никогда, кроме предпросмотра по отдельному preview-токену. |
| **Релиз** | Иммутабельный пронумерованный снапшот всей структуры сайта, созданный после чистого отчёта валидации. |
| **Канал** | Указатель на релиз: `live`, `staging`. Откат = смена указателя. |
| **Поток (stream)** | Контент с временем жизни, публикуемый вне релизов, мгновенно: новости, видео, промо, обучение, статус сервисов. |
| **Класс контента** | `marketing`, `legal`, `compliance`, `config`, `terminal`, `design-tokens`, `block-library`. Определяет, кто вправе публиковать и нужен ли аппрув compliance («четыре глаза»). |
| **Outbox** | Таблица событий, пишущаяся в той же транзакции, что и публикация. Гарантирует, что событие не потеряется. |

## Локали и юрисдикции

| Термин | Значение |
|---|---|
| **Локаль** | Язык. Ось, независимая от юрисдикции. |
| **Юрисдикция** | Правовой режим: регулятор, максимальное плечо, обязательные предупреждения, запрещённые продукты. Ось, независимая от локали. |
| **Фолбэк перевода** | Подстановка другой локали при отсутствии перевода. **Запрещён** для классов `legal` и `compliance`. Для маркетинга допустим, но ответ помечается `"fallback": true`. |
| **Разрешённое измерение** | Компонент кортежа `(site, releaseId, locale, jurisdiction, variant)`, от которого зависит ответ доставки. Участвует в ключе кеша и `ETag` — см. [[ADR-0003]]. |

## Дизайн и композиция

| Термин | Значение |
|---|---|
| **Data-bound блок** | Блок, который не копирует контент, а описывает запрос к коллекции (`dataSource: { collection, filter, sort, limit }`). |
| **Переиспользуемая секция** | Композиция блоков, сохранённая в библиотеку и подключаемая по ссылке на N страниц; правится в одном месте. |
| **Глобальные области** | Шапка, подвал, объявление-полоса, cookie-баннер, полоса риск-предупреждения, попапы. |
| **Токен** | Узел трёхуровневого графа: примитив → семантическая роль → токен компонента. Свободного CSS не существует, `block.style` берёт значения только отсюда. |

## Торговая часть

| Термин | Значение |
|---|---|
| **MDS** | Market Data Service — внешний источник вселенной инструментов (`/v1/instruments`, `/icons/{sym}.svg`). CMS хранит его **локальный снапшот** и никогда не ходит в MDS синхронно. |
| **Осиротевший символ** | Символ, исчезнувший из вселенной MDS. Помечается, показывается редактору, автоматически исключается из выдачи, попадает в отчёт. Наружу не утекает никогда. |
| **Витрина торговых условий** | Маркетинговая подача плеча / спреда / swap-free / лота. **Не источник истины** — см. [[ADR-0004]]. |
| **Реконсиляция** | Сверка локального состояния с внешним источником (вселенная MDS, торговое ядро) с алертом на расхождение. |

## Принципы

| Термин | Значение |
|---|---|
| **Fail-closed** | Отсутствие условия = отказ, а не пропуск. Нет ключа — 401, нет конфигурации — процесс не стартует. |
| **Тотальный маппер** | Маппер, который не падает на невалидной записи: исключает её из ленты и поднимает алерт. Требование ТЗ 1.3. |
| **Статус эфира** | `upcoming` / `live` / `past` — **вычисляется** из времени, не вводится руками. |

# ✅ Критерии приёмки (ТЗ разд. 11)

> [!important] Система принята, только если выполняется **всё одновременно**
> Каждый пункт должен быть подтверждён автотестом, учениями или демонстрацией из интерфейса — не словами.

- [ ] **Скорость запуска сайта.** Новый страновой сайт создаётся из шаблона за час без единой строки кода, наследуя бренд и региональные правила.
- [ ] **Черновик не утекает.** Невозможно получить через выдачу ни одним способом — доказано автотестом.
- [ ] **Публикация не ломает контракт.** Редактор не может опубликовать состояние, нарушающее контракт, комплаенс или доступность — сборка релиза отклоняет с внятным отчётом.
      🟠 частично: механизм работает и проверен — сборка отклоняется, отчёт с причинами сохраняется, снапшот не записывается. Действуют три проверки: готовность сайта, контраст WCAG AA, стоп-словарь обещаний доходности. Не хватает проверок, зависящих от модели страниц (битые ссылки, `alt`, риск-предупреждения, переводы) — они появятся с M3.
- [ ] **Откат за секунды.** Подтверждён на учениях.
- [ ] **Доказуемость.** На вопрос «что было опубликовано на apex-de 14 марта в 12:40 и кто это одобрил» система отвечает из интерфейса.
      🟠 частично: журнал аудита неизменяем на уровне БД, фиксирует изменения данных, вход и смену пароля ([[ADR-0014]]). Не хватает событий публикации и согласования (появятся со сборщиком релизов) и неудачного входа ([[DEBT-005]]).
- [x] **Изоляция тенантов.** Редактор сайта A технически не может прочитать или изменить данные сайта B — доказано автотестом. → [[TASK-009]], `src/platform/tenancy/isolation.integration.test.ts`, 20 тестов против живой БД, задание «Интеграционные тесты» в CI. Включая обращение по прямому идентификатору и запрет повышения собственных полномочий.
- [ ] **Устойчивость к падению MDS.** Не мешает ни редактировать, ни отдавать контент.
- [ ] **Видимость доставки.** Недоставленное событие инвалидации видно в интерфейсе и повторяемо одной кнопкой.
      🟠 частично: транзакционный outbox работает — событие пишется в одной транзакции с изменением, что доказано откатом транзакции; повторы с возрастающей задержкой; исчерпанное событие остаётся видимым с причиной. Не хватает экрана доставки и кнопки повтора.
- [ ] **Секреты.** Ни один не хранится в БД открытым текстом и не виден в UI/логах.
- [ ] **Fail-closed.** Запуск с неполной конфигурацией невозможен.
- [ ] **Тесты.** Покрытие доставки, доступа и релизного цикла — полное; CI блокирует мёрж при падении.

## Как отмечаем выполнение

Пункт отмечается только вместе со ссылкой на доказательство: путь к тесту, ID задачи или дата учений.

Пример: `- [x] Откат за секунды. → [[TASK-042]], учения 2026-11-14, 3.1 с`

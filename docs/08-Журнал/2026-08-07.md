# 2026-08-07

## Слой В целиком — [[ADR-0027]]

Шесть требований ТЗ 2.3 закрыты: редиректы с проверкой циклов, данные для карты сайта, директивы robots, граф hreflang между сайтами, шаблоны JSON-LD, canonical и OG с умолчаниями бренда.

Общее у них то, чего в списке нет: **это данные о данных**. Их легко завести полями формы — и тогда они начинают расходиться с тем, что описывают, молча.

### Разметка выводится, а не заполняется

Крошки — из пути. FAQ — из блоков аккордеона. Организация — из профиля и только на главной. Редактор выбирает одно из трёх: авто, статья, без разметки.

Причина та же, что у автоматического дисклеймера: поле, которое надо не забыть, забывают. Но здесь есть худшее следствие: заполненная руками разметка расходится со страницей при первой правке и превращается в **ложные данные для поисковика**.

### Собственная ошибка, пойманная тестом

Первая версия подставляла в хлебные крошки заголовок с применённым шаблоном бренда — «О компании — Apex». Это заголовок вкладки, попавший не туда.

Разделил: в манифест идёт заголовок документа (с шаблоном), в разметку — чистый. Тест на оба случая теперь стоит рядом.

### hreflang связывает по ключу, а не по совпадению путей

ТЗ говорит «связывается явно», и это существенно: у немецкой и французской версии пути **разные**, ради того они и разные. Совпадение путей связало бы однофамильцев.

Ключ одинаков у всех языковых версий, включая версии на других сайтах бренда. Поэтому сборка релиза впервые читает за пределами своего сайта — по поддереву бренда. Две страницы одного языка с одним ключом блокируют сборку: какая попадёт в hreflang, зависело бы от порядка чтения.

### Индексация запрещена по умолчанию

Асимметрия ущерба: закрытый по ошибке сайт открывают галочкой, открытый по ошибке — убирают из индекса месяцами. Для брокера к этому добавляется вторая цена: витрина стенда в поиске — это публикация непроверенных материалов от его имени.

Разрешение требуется от каждого языка: язык, закрытый по регуляторной причине, не открывается настройкой соседнего.

### Редиректы из истории путей не записываются в коллекцию

Выводятся при каждой сборке. Запись означала бы два источника истины про один переезд, и они разошлись бы после первой правки одного. При совпадении адреса побеждает правило, заведённое руками: автоматическое не перекрывает решение редактора.

## Ручной список отстал в третий раз — и заменён устройством

Тест изоляции сносит фикстуру по списку коллекций. Список отставал уже трижды: страницы, потом секции с меню, теперь профили SEO. Каждый раз падал **не тот** тест, который сломали, и объяснялось это не сразу.

Заменил выводом из конфигурации — той же функцией `findDependentCollections`, которой уже пользуется защита тенанта от удаления ([[DEBT-010]]). Обход идёт с конца списка коллекций: зависимая объявляется после той, на которую ссылается, поэтому материалы сносятся раньше своих авторов.

Признак, по которому это стоило заметить с первого раза, тот же, что и в прошлый: правило звучало как «не забудь дописать».

**Проверки:** 905 модульных + 200 интеграционных.

## Что осталось в M3

Модель части 2 закрыта целиком. Остался интерфейс: конструктор страниц, редактор меню, предпросмотр по preview-токену — [[DEBT-011]]. Это самая большая оставшаяся часть этапа и первое, что будет видно на приёмке.

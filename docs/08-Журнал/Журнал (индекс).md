# 📓 Журнал работ

Одна заметка на сессию, имя файла — дата `YYYY-MM-DD`. Пишется **в конце каждой сессии**. Фиксируем факт, а не намерение: что реально изменилось в репозитории и волте.

## Все записи

```dataview
TABLE WITHOUT ID
  file.link AS Дата, title AS Сессия
FROM #log
WHERE type = "log"
SORT file.name DESC
```

## Отвеченные

```dataview
TABLE WITHOUT ID
  link(file.link, aliases[0]) AS ID, title AS Вопрос, answered AS Отвечен, status AS Статус
FROM #question
WHERE status = "answered" OR status = "closed" OR status = "assumed"
SORT answered DESC
```

> [!note] Статус `assumed`
> Означает: ответа нет, работаем по допущению из разд. 1 ТЗ, **риск принят заказчиком явно**. Молчание допущением не является.

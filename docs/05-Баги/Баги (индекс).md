# 🐛 Баги

Шаблон: [[Шаблон бага]]

> [!important] Правило записи
> Баг записывается **в момент обнаружения** — даже если чинить будем не сейчас, даже если он не в нашем коде. Ненаписанный баг равен несуществующему.

> [!danger] Автоматический `p0` в регулируемом домене
> Приоритет `p0` независимо от вероятности, если баг допускает:
> - утечку черновика в выдачу;
> - доступ к данным чужого тенанта;
> - отдачу наружу ответа, не прошедшего валидацию схемой;
> - показ контента без обязательного риск-предупреждения в юрисдикции, где оно требуется;
> - утечку «осиротевшего» символа MDS;
> - расхождение витрины торговых условий с торговым ядром.

## Открытые

```dataview
TABLE WITHOUT ID
  link(file.link, aliases[0]) AS ID, title AS Симптом, priority AS Приоритет, status AS Статус, updated AS Обновлён
FROM #bug
WHERE type = "bug" AND (status = "open" OR status = "in-progress")
SORT priority ASC
```

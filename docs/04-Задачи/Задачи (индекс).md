## Активные

```dataview
TABLE WITHOUT ID
  link(file.link, aliases[0]) AS ID, title AS Задача, status AS Статус, priority AS Приоритет, stage AS Этап, updated AS Обновлено
FROM #task
WHERE type = "task" AND status != "done" AND status != "cancelled" AND status != "backlog"
SORT priority ASC, file.name ASC
```

## Заблокированные — и чем

```dataview
TABLE WITHOUT ID
  link(file.link, aliases[0]) AS ID, title AS Задача, related AS Блокировано
FROM #task
WHERE status = "blocked"
```

## Бэклог

```dataview
LIST
FROM #task AND #status/backlog
```

Полный состав этапов — [[Дорожная карта]]. Задачи детализируются при входе в этап, чтобы не плодить мёртвые записи.

## Закрытые

```dataview
TABLE WITHOUT ID
  link(file.link, aliases[0]) AS ID, title AS Задача, updated AS Закрыта
FROM #task
WHERE status = "done" OR status = "cancelled"
SORT updated DESC
```
